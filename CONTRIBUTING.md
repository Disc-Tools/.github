# Contributing to Disc-Tools

Choose the repository for the affected website. Read its README and any repository-specific contribution instructions before editing.

For bugs, include the page, browser, expected behavior and reproducible steps. Use Discussions for questions and feature ideas.

For pull requests, describe the user-visible change, the checks performed and any remaining verification. Keep changes focused and test affected layouts on desktop and mobile.

Report vulnerabilities privately to info@disc-tools.de.
